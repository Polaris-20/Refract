# REFRACT / 折光 v0.9.1 · 首个公开预览版

把世界调成你的频率。

折光是一个 Windows 本地音乐播放器：透出桌面的玻璃、工业风排版、同步歌词，以及留在自己电脑里的音乐收藏。

## 这一版可以做什么

- 桌面玻璃“关闭 / 聚焦时启动 / 保持”三档，聚焦切换使用系统自然渐变。
- 正常、置顶小窗、沉浸全屏三种窗口，支持切换动画。
- 本地音乐导入、歌曲信息与封面编辑、收藏和歌单、播放队列整理。
- LRC / SRT / JSON / TXT 歌词导入与拖入、同步高亮、桌面悬浮歌词。
- 封面取色、实时频谱、可调 1–12 秒交叉淡化。
- 三段项目原创演示声景，第一次打开即可试听。

## 下载与运行

下载 **Refract-Windows-v0.9.1.zip**，完整解压后打开 `Refract.exe`。

本次面向 **Windows 11 x64**，需要 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) 和 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)。玻璃材质需要 Windows 11 22H2 或更新版本，程序未签名。

源码包为 **Refract-source-v0.9.1.zip**；**SHA256SUMS.txt** 提供两个下载包的 SHA-256 校验值。

已在本地使用过旧版的用户：退出程序后替换程序文件，保留原来的 `data/`。直接在新目录运行会使用独立曲库。

## 已知边界

- 这是预览版，尚未完成跨机器、长时间播放与超大曲库的全面验证。
- 玻璃表现受 Windows 透明效果、节能和系统版本影响；“保持”使用的兼容接口可能回退。
- 音频过渡为交叉淡化，没有自动对拍或采样级无缝播放。
- 暂无联网找词、均衡器、全局媒体热键或自动更新；不支持 DRM 音乐。

首发前检查包含构建与纯逻辑检查；历史真实界面验证及仍待手动确认的部分见仓库中的 `docs/VALIDATION.md`。

欢迎通过 Issues 反馈系统版本、复现步骤及截图。请隐去个人路径，不要上传整个曲库或未经授权的音乐。
